https://github.com/tt-a1i/archify · pushed 2026-07-09 · triaged 2026-07-13 · seen on github-trending

**What it is:** An agent skill (for Claude, Codex CLI, opencode) that turns a plain-English system description into a polished architecture/sequence/data-flow/lifecycle diagram — a single self-contained HTML file with dark/light toggle, clipboard copy, and up-to-4x PNG/JPEG/WebP/SVG export.
**Reusable for us:** A directly invokable skill for a task we don't currently cover (architecture diagramming) — complements `dataviz` (which is for charts/data, not system diagrams).
**Token / effectiveness angle:** Generating a diagram as a single portable HTML artifact (vs. iterating on ASCII/mermaid by hand) is a cheap way to produce a shareable visual from a short description.
**How to adopt:** Recommend to the user as a skill/plugin to install for architecture-diagram tasks; not yet trialed by us, so keep it at "recommended" until someone actually runs it and files field notes.
