**What it is:** A reference implementation of "context engineering" (corpus, retrieval, injection, + 2 more components) run end-to-end against a real codebase (Spring PetClinic) on Amazon Bedrock — the code companion to an outcomeops.ai glossary post.
**Reusable for us:** Conceptually adjacent to what `index.json`/`CATALOG.md` already do here (a version-controlled, retrievable corpus of reusable knowledge), but this is a teaching/reference repo tied to Bedrock, not a portable tool. Low stars, very new.
**Token / effectiveness angle:** The five-component framing (corpus/retrieval/injection/...) is a useful vocabulary for talking about how this repo's own index works, even without adopting the code.
**How to adopt:** Watch. Read for conceptual framing if we ever redesign how `index.json` retrieval/injection works; not a dependency to install.
