**What it is:** A CLI (`npx claude-code-templates@latest`) and web catalog (aitmpl.com) of 100+ installable Claude Code agents, commands, hooks, MCPs, settings, and skills, sponsored/badged by Anthropic's Open Source Program.
**Reusable for us:** This is the closest analog to claude-common's own mission, at larger/commercial scale. Rather than adopt the tool itself, mine aitmpl.com/the repo for specific agents/commands/hooks worth porting into `.claude/agents`, `.claude/commands`, or `hooks/` when a concrete need arises.
**Token / effectiveness angle:** Same thesis as claude-common (reusable Claude Code assets instead of reinventing), but browser/CLI-driven rather than a jq-queryable index — good for human browsing, less agent-first than our `index.json`.
**How to adopt:** watch — treat as a sourcing ground for specific components, not a wholesale dependency.
