**What it is:** A personal Claude Code plugin (also its own marketplace) whose one skill, `kindle-highlights`, recovers export-blocked Kindle highlights (truncated/hidden by Amazon's undocumented export limit) by cross-referencing the Mac Kindle app's synced annotation positions and the Cloud Reader's rendered pages. Well-documented, proven on real books (2,733 highlights, 1,038 export-blocked, all recovered).

**Reusable for us:** None — the technique (matching character-length-known highlights against a rendered-page sweep) is specific to Kindle's export format and not transferable to Claude Code agent effectiveness.
