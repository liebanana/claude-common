**What it is:** A pre-indexed, auto-syncing semantic code-intelligence graph (Node.js, self-contained binary) supporting Claude Code, Cursor, Codex, OpenCode, Hermes Agent, Gemini, Antigravity, and Kiro — gives agents surgical context and fewer tool calls, 100% local, signed/attested releases.
**Reusable for us:** Same category as `tirth8205/code-review-graph` and `MinishLab/semble` (indexed code search instead of grep+read) but broader multi-harness support and a 1.0 release with signed builds — worth comparing the three head-to-head before picking one to standardize on.
**Token / effectiveness angle:** Pitch is explicitly "surgical context, fewer tool calls" — directly reduces the read-heavy token cost of large-repo agent work.
**How to adopt:** Trial alongside `semble` and `code-review-graph` on the same repo/task to compare token savings and setup friction; record the comparison as field notes before recommending one.
